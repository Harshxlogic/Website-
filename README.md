# Harsh Vardhan Anand — Portfolio
Requires Node.js 18+.
    npm install
    npm run dev      # open the URL it prints (usually http://localhost:5173)
    npm run build    # production build in /dist
Edit your GitHub link in src/App.tsx (const GITHUB).

## Scroll effects
- Skills / Experience / More: stacking cards (`StackCard` in src/App.tsx). Tweak the card colors in `decks`.
- Skills / Experience / Projects each open with a pinned exploded-view assembly (`Exploded` in src/Exploded.tsx).
  Edit the `stageSkills`, `stageExperience` and `stageProjects` objects in src/App.tsx to change the parts and captions.
  Pass `height={380}` (vh of scroll) to make an animation longer or shorter.
- Hero bust: public/bust-hd.png (4x upscale of bust.png), animated in src/BustHead.tsx.
